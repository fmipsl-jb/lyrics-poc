# Lyrics — Audio Transcription PoC

A proof-of-concept desktop app for **Transcription of Lyrics & Speech**.

Load an audio file, hit **Scan**, and the app transcribes it with
[OpenAI Whisper](https://github.com/openai/whisper), showing a live progress bar.
On success it produces **timecoded lyrics** that you can save as a Markdown
(`.md`) file to any directory you choose.

> Scope: this PoC covers the *"transcribe from scratch with automatic timecode
> alignment"*. Aligning pre-existing lyrics, in-app
> editing, and integration are out of scope for the PoC.

---

## What it does (PRD mapping)

| PRD requirement | How it's met |
| --- | --- |
| Choose a file and load it | Native file picker (`Choose file…`) |
| A **Scan** button | `Scan` triggers transcription |
| Progress bar | Live, determinate bar driven by Whisper's real decoding progress |
| Human-readable success/error | Clear dialog messages for every outcome |
| Lyrics **with timecodes** | Each line prefixed `[MM:SS.mmm]` |
| Saved as `.md` to a chosen directory | Native "save as" dialog |
| macOS + easily built for Windows | Pure Python + Tkinter (stdlib GUI); only ffmpeg is OS-specific |
| Newest machines / ARM | Runs natively on Apple Silicon (arm64) and Windows on ARM64 |

## Requirements

The launcher scripts install and keep these current **automatically** (see below),
so on a fresh machine you normally don't install anything by hand:

- **Python 3.12** with **Tk 8.6+** bindings (for the GUI to render correctly).
- **ffmpeg** (Whisper uses it to read audio).
- **Homebrew** on macOS / **winget** on Windows (used to install the above).

Internet access is needed on first run (to install prerequisites and download
the Whisper model once; both are then cached).

### Automatic setup (fresh machine friendly)

`run.sh` (macOS) and `run.bat` (Windows) are **self-provisioning and idempotent**:

- **macOS** — `run.sh` will, as needed: install Homebrew; install/upgrade
  `python@3.12`, `python-tk@3.12`, and `ffmpeg`; then build the virtual
  environment and install Python dependencies. Re-running upgrades what's
  present rather than reinstalling, so everything stays up to date. It also
  rebuilds the venv automatically if it was created by a different/older Python.
- **Windows** — `run.bat` uses `winget` to install Python 3.12 and ffmpeg if
  they're missing, then sets up the environment.

You can point the scripts at a specific interpreter and skip auto-provisioning:

```bash
PYTHON=/path/to/python3 ./run.sh        # macOS/Linux
set PYTHON=C:\path\to\python.exe && run.bat   # Windows
```

## Quick start

### macOS

```bash
# One command does everything: installs prerequisites (Homebrew, Python 3.12,
# python-tk, ffmpeg) if missing, sets up the environment, and launches the app.
cd ~/GitHub/Lyrics
./run.sh
```

### Windows

```bat
REM One command: installs Python 3.12 + ffmpeg via winget if missing,
REM sets up the environment, and launches the app.
cd %USERPROFILE%\GitHub\Lyrics
run.bat
```

> If ffmpeg was just installed on Windows, open a **new** terminal so it's on
> PATH, then run `run.bat` again.

If you prefer to do it manually:

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## How to use

1. **Choose file…** — pick a `.wav`, `.mp3`, `.m4a`, `.flac`, etc.
2. **Scan** — the app loads the Whisper model (first run downloads it) and
   transcribes. Watch the progress bar.
3. On success, a dialog reports how many timecoded lines were found and the
   detected language.
4. **Save lyrics as .md…** — choose where to save. Example output:

```markdown
# Lyrics — song.mp3

> Generated by the **Lyrics** PoC using OpenAI Whisper.
> Source file: `/Users/you/Music/song.mp3`
> Model: `base`
> Detected language: `en`
> Timecodes are shown as `[MM:SS.mmm]` (or `[HH:MM:SS.mmm]`).

---

[00:00.000] This is the first line of the song
[00:04.250] and this is the second line
```

## Configuration

The Whisper model size is set in `app.py`:

```python
DEFAULT_MODEL = "base"   # tiny | base | small | medium | large | turbo
```

- `tiny`/`base` — fast, small download, good for demos.
- `small`/`medium` — better accuracy, larger download, slower.
- Non-English audio: the multilingual models (`base`, `small`, …) auto-detect
  language. `turbo` is fast but not suited for translation.

## Building a standalone app (optional)

For a distributable, GUI-clickable build, use
[PyInstaller](https://pyinstaller.org/):

```bash
pip install pyinstaller

# macOS (produces Lyrics.app in dist/)
pyinstaller --windowed --name Lyrics app.py

# Windows (produces dist/Lyrics/Lyrics.exe)
pyinstaller --windowed --name Lyrics app.py
```

Notes:
- Build **on the target OS/architecture** you want to ship (PyInstaller is not a
  cross-compiler). Build on Apple Silicon for an arm64 macOS app; build on
  Windows-on-ARM (or x64) for the matching Windows binary.
- ffmpeg is a separate runtime tool — either bundle the `ffmpeg` binary and add
  it to the app's path, or document that users install it (as above).
- The Whisper model still downloads on first run unless you pre-bundle the `.pt`.

## Troubleshooting

**`ModuleNotFoundError: No module named 'pkg_resources'` while installing Whisper.**
`openai-whisper`'s build step imports `pkg_resources`, which newer setuptools
(≥ 81) removed. The `run.sh` / `run.bat` scripts handle this automatically by
pinning `setuptools<81` and disabling pip build isolation. If you install
manually, do the same:

```bash
pip install "setuptools>=68,<81" wheel
pip install --no-build-isolation -r requirements.txt
```

## Known limitations (PoC)

- **First-run model download** can take a while depending on model size/network.
- **CPU inference** on laptops is slower than GPU; `base` keeps it reasonable.
- Progress reflects Whisper's internal decode loop; if a future Whisper release
  changes internals, the bar falls back to advancing only at completion (the app
  still works).
- No in-app editing of results yet (that's a full-feature item, not
  the PoC).
